# TowerDefense

> 个人练习项目 · 目标不是做一款完整的游戏，而是把 **数据驱动 / 对象池 / 事件解耦** 这三件事做扎实，作为投 Unity 客户端实习的作品集。
> 引擎版本：Unity 2021.3.45f2c1 · 模板：3D（Built-in）

---

## 一句话玩法

在怪物行进路径旁建造炮台，抵挡 10 波敌人的进攻，守住基地。

## 核心功能（第一版只做这 5 条，别加）

1. **波次刷怪**：按配置生成敌人，敌人沿固定路径点走到基地
2. **炮台建造**：点击空地放置炮台，消耗金币
3. **自动战斗**：炮台锁定射程内最近的敌人，按冷却时间发射子弹
4. **伤害与死亡**：敌人扣血、死亡给金币；漏怪扣基地血量
5. **胜负与存档**：10 波打完判定胜负，存档记录已通关波数

## 我要练的 3 个技术点（面试要能讲出来的）

| 技术点 | 具体做法 | 面试时怎么讲 |
|---|---|---|
| **数据驱动** | 敌人属性、炮台数值、波次配置全部用 `ScriptableObject`，不写死在代码里 | "改数值不用改代码，策划能自己配" |
| **对象池** | 敌人与子弹不用 `Instantiate/Destroy`，用自己写的 `Pool<T>` 复用 | "频繁实例化会产生 GC 峰值导致卡顿，池化后 Profiler 里 GC Alloc 归零" |
| **事件解耦** | 金币变化、敌人死亡、基地掉血走事件广播，UI 只订阅不反向引用 | "UI 和玩法互不引用，加一个界面不用改玩法代码" |

## 里程碑

| 周 | 目标 | 验收标准 |
|---|---|---|
| 第 2 周 | 敌人沿路径移动 + 波次生成 | 能连续刷出 5 波怪并走完全程 |
| 第 3 周 | 炮台索敌、发射、结算伤害 | 能从第一波玩到基地被打爆 |
| 第 4 周 | 事件系统 + 对象池 + 存档 | Profiler 里看不到持续 GC Alloc |
| 第 5~6 周 | 重构 + 文档 + 演示视频 | 换个机器能照着 README 跑起来 |

## 目录约定

```
Assets/
  _Project/              # 自己写的一切都放这里，方便和外部资源区分
    Scripts/
      Core/              # 事件系统、对象池、单例、通用工具
      Data/              # ScriptableObject 配置类
      Gameplay/          # 敌人、炮台、子弹、波次、关卡流程
      UI/                # 界面脚本
    Prefabs/
    ScriptableObjects/
    Scenes/
    Art/                 # 占位几何体材质等
  ThirdParty/            # 外部插件、免费美术资源，一律隔离在这里
```

## 编码约定

- 类名/方法名 `PascalCase`，私有字段 `_camelCase`，常量 `UPPER_SNAKE`
- 一个脚本一个职责，超过 200 行就该拆
- 不在 `Update` 里 `GetComponent` / `Camera.main`，一律 `Awake` 里缓存
- 提交信息格式：`feat: 敌人路径移动` / `fix: 炮台冷却不生效` / `refactor: 抽出对象池`

## 占位美术说明

第一版全部用 Unity 自带几何体（Cube = 敌人/炮台，Sphere = 基地，Capsule = 路径点标记），**不引入任何外部美术资源**。等玩法跑通、第 5 周以后再考虑换素材。
